# Tags

One file per tag, in the folder of its group: subject, exam, skill, level or audience.
The file name is the tag's slug (lowercase letters, numbers and hyphens) and never changes.
Each file has `title` (what students see), `description` (one line, shown on the tag page)
and `search` (other words students might type; used only by search).

Add or edit tags in Pages CMS under "Tags: Subject area" and so on, or by adding a file here.
